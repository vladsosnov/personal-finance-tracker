# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Instead, report them privately through GitHub's private vulnerability reporting for this repository. If that is not available, contact the repository owner directly through GitHub and include `Security` in the subject or message.

Please include as much of the following as possible:

- a description of the issue and its impact
- the affected area (`frontend`, `backend`, authentication, billing, deployment, etc.)
- steps to reproduce
- a proof of concept or sample request if available
- any suggested mitigation

We aim to acknowledge reports on a best-effort basis within 5 business days.

## Supported Versions

Security fixes are handled on a best-effort basis for the current default branch of this repository.
Older commits, forks, and unofficial deployments are not guaranteed to receive fixes.
